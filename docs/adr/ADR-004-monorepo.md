# ADR-004 저장소 구성: 모노레포 1개
상태: 채택 (Ⅷ장, 2026-07) · ADR-001 보완
맥락: 배포 단위는 2개(iOS 앱 / 서버 계열)다. 저장소를 나눌지 결정해야 Sprint 0을 실행할 수 있다. 팀은 4인, 한 학기.
결정: KPUCE/InnerMap 모노레포 하나(/ios /server /admin-web /batch /docs). 배포 단위 분리는 CI 2계열(경로 필터)로 구현한다.
근거: ① 추적성의 실(R-번호→이슈→PR→커밋)이 저장소 경계에서 끊기지 않는다 ② 4인 팀에서 저장소 2개는 리뷰·보드를 분산시킨다 ③ docs/가 한곳에 살아야 코드와 함께 늙지 않는다 ④ iOS 서명 격리는 CI 시크릿 스코프로 충분하다.
트레이드오프: 도구 체인 혼재, 컴포넌트별 권한 분리 불가(4인 팀에서 실해 없음).
