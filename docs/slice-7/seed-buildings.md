# 시드 데이터 원본 — 한국공학대학교 본교 건물 좌표

슬라이스 #7·#8의 검색 API가 올라탈 고정 시드 데이터의 **원본 기록**이다. 스키마가 확정되기 전 단계이므로 여기에는 원시 좌표와 출처만 둔다. 마이그레이션·시드 파일로의 변환은 2단계 상세 설계에서 스키마를 정한 뒤 수행한다.

## 출처와 라이선스

· 출처: OpenStreetMap, Overpass API로 조회
· 조회 일자: 2026-07-26
· 대상 범위: 한국공학대학교 본교(경기도 시흥시 정왕1동). 조회 bbox = 남 37.3378 / 서 126.7300 / 북 37.3427 / 동 126.7366
· 캠퍼스 위치 확인: Nominatim 조회 결과 way/234844934, 중심 37.3402397 / 126.7333516
· **라이선스: ODbL (Open Database License).** 이 데이터에서 파생된 시드 파일과 교재 지면에는 "© OpenStreetMap contributors" 출처 표시를 유지해야 한다.

재현용 질의(Overpass QL):

```
[out:json][timeout:90];
(way[building](37.3378,126.7300,37.3427,126.7366);
 relation[building](37.3378,126.7300,37.3427,126.7366););
out center tags;
```

조회 결과 건물 폴리곤 74개 중 이름이 있는 것은 21개다. 나머지 53개는 이름이 없어 검색 대상이 되지 못한다. 좌표는 폴리곤의 중심점(`out center`)이다.

## ADR-003과의 관계 (교재에 밝힐 것)

ADR-003은 지도·좌표 데이터의 주 출처를 공공데이터(도로명주소 건물 API, V-World 폴리곤)로, 보조를 네이버 지도로 정했다. OSM은 그 목록에 없다. 이는 결함이 아니라 **개발용 시드와 운영 데이터의 출처가 다른 경우**이며, 교재는 이 사실을 밝힌다. 운영 단계의 수집 배치(이슈 #10)는 ADR-003대로 공공데이터를 쓴다.

## 별칭이 없다

OSM에는 통칭·줄임말이 없다. 학생들이 실제로 쓰는 '공A', '본부', '창조관' 같은 말은 이 데이터에 담기지 않는다. 별칭 검색을 슬라이스에 포함한다면 아래 중 하나를 골라야 한다.

· 저자가 아는 실제 통칭을 손으로 넣는다 — 가장 현실적이지만 저자의 시간이 든다
· 규칙으로 생성한다(공학관A동 → 'A동', '공학관A', '공A') — 빠르지만 실제 사용례와 다를 수 있다
· 슬라이스에서 제외하고 이슈 #12로 미룬다

무엇을 고르든 교재에는 그 출처를 밝힌다. 손으로 넣은 별칭은 '팀 추정'이 아니라 '저자 확인'이고, 규칙 생성분은 그렇게 표기한다.

## 사용 지침

이 파일은 원본 기록이므로 수정하지 않는다. 스키마 확정 후 여기서 파생한 시드 파일을 별도 경로에 만들고, 그 파일 머리에 이 문서와 ODbL 출처를 참조로 남긴다.
