# 아이디어 보관소

백로그는 실행할 목록이다. 출처(R-번호)가 없거나 이번 범위 밖인 항목은 이슈로 만들지 않고 여기 둔다.

| 항목 | 사유 | 재검토 시점 |
|---|---|---|
| 오류 신고 기능 (R-21) | 이번 학기 미구현 결정 — 스토어 리뷰·이메일로 대체(ⅩⅣ장 주간 점검 루틴) | 다음 학기 |
| 즐겨찾기 클라우드 동기화 | 출처 R-번호 없음 · 계정·로그인 배제 결정과 충돌 | 범위 재논의 시 |
| 음성 명령으로 브리핑 시작 | SRS 배제 항목(소음 환경 오인식 위험) — 기각 | 기각 유지 |
