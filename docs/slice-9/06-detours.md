# 06 막힌 지점·잘못 든 길 — #9 (slice-7의 06 이어짐)

## D8 — 꺼둔 로컬 서버가 만든 가짜 빨강
- iOS 구현 후 첫 전체 실행에서 기존 UI 테스트 3개가 갑자기 실패. 원인은 코드가 아니라 **직전 세션 정리 때 꺼둔 로컬 API 서버**(UI 테스트의 외부 전제). 서버 재기동만으로 초록 복귀.
- 교훈: 외부 전제(서버+시드)가 있는 테스트는 실패 시 전제부터 확인 — 코드 회귀로 오판하기 쉽다. UI 테스트의 CI 편입 논의(미결)에 "전제를 세우는 스텝"이 포함되어야 하는 근거이기도 하다.

## D9 — 시뮬레이터 패널 손 조작 한계 재확인 (D6 재발)
- 결과 행 탭이 텍스트 필드로 라우팅되는 등 좌표 탭이 불안정(D6에서 본 유형). 손 데모 대신 **상세 진입을 XCUITest로 검증**하는 쪽으로 전환 — `test_상세진입_시뮬레이터는_거리만안내`가 행 탭→상세 로드→"방위를 확인할 수 없어 거리만 안내" 문구까지 확인.
- 부수 효과: 시뮬레이터의 나침반 부재가 오히려 ADR-005 ③ 축소 경로(정확도 무효 → 거리만+고지)의 실검증이 됐다 — 실기기에서만 검증 가능한 것은 .hour 경로의 실사용뿐.
